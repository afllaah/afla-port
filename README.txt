# Aflaa Portfolio

Static portfolio website — no npm, no framework, no build step.

## Run
1. Extract the ZIP.
2. Open `index.html` in Chrome/Edge/Safari.
3. To publish on GitHub Pages, upload the contents of this folder to a repository and enable Pages.

## Included
- Light / dark mode
- Responsive mobile layout
- Smooth scrolling and reveal animations
- Project detail modal
- Email contact form using `mailto:`
- Instagram link
- User-supplied profile and project images
